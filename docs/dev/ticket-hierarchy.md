# Ticket hierarchy and starting order

Epic #1 is the first release for Folt. Record delivery groups and
their children here as they are created.

| Issue | Responsibility | Parent |
| --- | --- | --- |
| #1 | v0.1.0 release | None |

Use native parent links. Default independent work to epic #1 and use bounded
children for delivery groups when scoped. Cross-repository references must
include the repository name or full URL; do not assume issue numbers match
between repositories. Commit/push authorization remains separate from
implementation.
