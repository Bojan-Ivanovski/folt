# Security policy

Folt is in early development. Security fixes target the current `develop`
branch; there are no supported stable releases yet.

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/Bojan-Ivanovski/folt/security/advisories/new).
Include the affected revision, reproduction steps, expected impact and any
suggested fix. Do not disclose sensitive details in a public issue or pull
request. If private reporting is unavailable, wait until it is enabled rather
than posting the vulnerability publicly.

The maintainer will assess the report and coordinate a fix and disclosure with
the reporter. There is no guaranteed response or remediation time at this stage.
