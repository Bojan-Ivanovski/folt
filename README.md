# Folt

`folt` is a standalone command-line tool for managing documents, called Folios,
the way `git` manages source code. It works on Folios locally and exchanges them
with remotes. [Foltivo](https://github.com/Bojan-Ivanovski/foltivo-backend) is the
first intended remote host, much as GitHub is for Git, but `folt` does not depend
on it.

## Status

Early planning. The Folio format, sync protocol and command set are not selected
yet; see [the stack](docs/dev/stack.md). `folt` is developed in this repository,
independently of the Foltivo backend and frontend.
